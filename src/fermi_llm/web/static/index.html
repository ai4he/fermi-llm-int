Multi-Agent Workflow

                        
The Master Agent analyzes your prompt, consults FermiPy documentation (RAG), and generates YAML configuration + Python script using the selected LLM.

                        
The Validation Agent iteratively repairs and validates the config through 4 levels:

                        
    
                            
  1. Level 1: YAML parsing + FermiPy ConfigManager validation
    2. 
                            
  2. Level 2: GTAnalysis instantiation (target / ROI model check)
    3. 
                            
  3. Level 3: Full gta.setup() execution with real Fermi-LAT data
    4. 
                            
  4. Level 4: gta.optimize() + gta.fit() for science-quality results
    5. 
                        

                        
If any level fails, the Validation Agent diagnoses the error and applies targeted deterministic repairs (up to 5 iterations).
